## 1. 方針：別セッションを推奨、ただし「別製品」にはしない
- **はい。中古（主に平安期）・中世（主に鎌倉～室町・戦国期）の地図調査は専門の別セッションを推奨する。** 江戸期の国絵図を単純に年代スライダーで遡る研究ではなく、史料批判・図像・国郡制・荘園領域の検討を要する。
- そのセッションの成果物はまず**資料候補表／書誌／年代／権利／採否案**。エンジンCore/既存UI/本番データには直接書き込まない。研究と実装は並行できる。
- 中古・中世の国境が現存資料に描かれていなくても、研究結果が「不明」なら有用な結論として記録する。近世図形を1170/1185/1689の正しい領域と偽ることを避ける。
- 「中古～中世の日本図」「局地的な荘園絵図」「研究者による現代の復元図」は、**対象地理・製作年代・用途・精度が異なる**別資料クラスとして比較する。
- 全時代/全国を網羅したGISポリゴンの作成はこのトラックの成功条件としない。最初は**屋島・讃岐（1185）／深川・武蔵（1689）／陸奥の分割（1868）**に結びつく優先候補を探す。

## 3. 紙の本・未デジタル図版から補完する実務フロー
1. **まず探索**: NDLサーチ/大学史料編纂所/公文書館/自治体史で書名・巻号・図版番号・ページ・所蔵先・刊行年・資料成立年を記録。画像が既に公開されている場合は再撮影前にそちらの利用条件を確認。
2. **優先判断**: 現行UIに実際に不足している情報（たとえば「1185屋島の水陸関係を推定する根拠」「1689の近接年代の国絵図」）へ寄与するかで並べる。単に古い地図がある、というだけで取り込まない。
3. **閲覧・所蔵照会**: 来館/館内限定電子閲覧/複写申請/研究者への問い合わせなどの適法な方法で、該当ページと図の作製年代・縮尺・凡例・史料名を確認。閲覧可能でも自動的にネット再配布許可とは限らない。
4. **権利を分けて確認**: (a)原図の著作権等、(b)刊本の写真/解説/トレースの権利、(c)所蔵機関の利用条件、(d)必要なクレジット、(e)データや画像をアプリで再配布する形態。未許諾は内部研究のみ、公開アセットに複製しない。
5. **最小抽出**: 図版の所在、確認した地名や表記、地図が示す地物、主張の出典ページ、差異・矛盾、要約に留める。生画像/切出し/独自トレースの配布は、個別の権利確認・許諾後。
6. **地図として使えるか判断**: 記号的・鳥瞰的な絵図は地名関係を読む参考資料。精密な位置合わせの前提を欠く場合は\`georeference_status: not_applicable\`とし、GIS境界を生成しない。位置合わせが妥当な縮尺の資料に限り、基準点/変形手法/残差/時代差を記録して候補作成。
7. **本体への受渡し**: 既存GISデータ契約の\`source_created_time\`, \`attested_time\`, \`valid_time\`, \`geometry_observed_time\`, \`rights\`, \`position_quality\`, \`source_ids\`を使う。未承認の図形は\`geometry=null\`のまま／候補限定で保持。後世図の比較表示は\`comparison_only\`にする。
8. **人手レビューと小規模採用**: 最初は1資料・1地域・1用途を試し、史料妥当性・UI表現・権利に問題がなければ次を増やす。

## 4. 資料1件ごとに必須となる「最小成果表」
\`\`\`yaml
record_id: "research:medieval:001"
title: null                     # 書名・図名、国別絵図なら対象旧国
creator_or_editor: null
original_or_copy: unknown       # original | later_copy | printed_edition | modern_reconstruction
subject_time: {start_year: null, end_year: null}
source_created_time: {start_year: null, end_year: null}
attested_time: {start_year: null, end_year: null}
reference: {library: null, call_number: null, volume: null, page_or_figure: null, url: null}
spatial_scope: null             # 例: 荘園単位/国単位/列島概略図
georeference_feasibility: unknown  # possible | not_applicable | needs_review
accuracy_notes: null
rights: {viewable: unknown, image_redistribution: unknown, derivative_data: unknown, attribution: null}
use_case: null                  # 本体のどの画面/年を補うか
evidence_kind: unreviewed
review_status: source_not_audited
recommendation: hold
\`\`\`
記載時点で分からない情報は**null/unknown**で保持し、後世版の刊行年を原図作製年と取り違えない。個々の書誌の網羅的収集より、実際のUIに役立つ資料を少数優先する。

## 5. 本体に返すべき成果と、返さない成果
**返すもの**
- 重要資料候補の短い一覧。各資料の年代・局地/全国・典拠の強弱・公開利用の可否。
- 1689元禄国絵図など、**対象年と資料年が異なる**ことを分かる比較図表示提案。
- 中古・中世で国境形状が不確かな場合の注記・地名や国郡関係の候補。
- 権利確認済みなら小規模テスト用の画像参照URIや図形候補（アプリ本体への自動公開不可）。

**返さないもの**
- 未許諾の刊本スキャン、研究者の復元図の勝手なトレース、所有者に無断の画像複製。
- 行基図のような模式的・観念的日本図から機械的に引いた国境座標。
- 1185年の海岸線や合戦の正確な点としての現代参照地点。
- 別の年代判定エンジン、別の公開repo、研究と根拠のない広域GeoJSON。

> 旧国名アトラスの中古・中世地図史料調査を担当。正本は yama-books/basho-atlas の Draft PR #1 と docs/HISTORICAL_GIS_KYUKOKU_MASTERPLAN_20261019.md。コードや既存UIを変更しない。国立国会図書館リサーチ・ナビ、東京大学史料編纂所荘園絵図、国立公文書館国絵図、大学・自治体史の図集から、古代・平安・鎌倉・室町期および1689年比較用の有力資料を少数選別。元図の成立年・写しの年代・刊本刊行年を区別し、利用権・図面の位置合わせ適否を調べる。史料が模式図なら境界GISを作らず「地名・位置関係の候補」として整理。書誌・年代・所蔵・権利・推奨採否・必要な次工程を記載した結果を docs/HISTORICAL_GIS_PREMODERN_* に残し、既存アプリ・国ID索引・旧国境データを変更しない。本体v0.3の完成を妨げない。進捗・未確認点・最新コミットを引き継ぐ。

## 7. 資源制約と調査の打切り基準
- 入口の調査資料は**3～5点から**。具体的なUI価値が判明してから対象を増やす。
- 未公開図版を入手するための長期間の待ち・高額な複写・全巻走査は最初のエンジン完成に必須としない。
- 史料の図形化に十分な縮尺/基準点/確実な年代がなければ、無理にスキャン/トレース/補間しない。
- 最初の納品は地図画像でなく、**出典・利用条件・時代適合の確実な調査メタデータ**でもよい。
