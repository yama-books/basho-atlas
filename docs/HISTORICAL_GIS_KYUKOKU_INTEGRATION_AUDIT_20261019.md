## 2. 正式照合したID関係
CODH公式[国・地域IDデータセット](https://codh.rois.ac.jp/province/)は、江戸期からの\`P001–P070\`と、明治の分割後\`P100–P117\`を区別している。
- \`P010\` = 武蔵。1689年深川の「武蔵国」候補に対する**名称IDリンク**。
- \`P002\` = 分割前の陸奥。1689年の岩沼/松島「陸奥国」候補に対する**名称IDリンク**。
- \`P111\` = 磐城、\`P112\` = 岩代、\`P113\` = 陸前、\`P114\` = 陸中、\`P115\` = 分割後の陸奥。**P115は1689年の陸奥として利用しない**。
- この表は江戸～明治期の索引用IDであり、1185年への同一時点の適用・座標からの旧国判定・史実認定を保証しない。\`1689\`の2種類のみ機械補助IDとして提供し、他年代は \`not_audited_for_year\` とする。
- \`1868\` は変化の年内時点を別資料で確定できない限り \`transition_undetermined\`。後世の名称だけを使って新IDを推測しない。

重要: CODHの\`P\`系列、Geoshape境界の\`K\`系列、幕末近世村の別\`K\`系列は**別のID空間**。仮に数字が同じでも交換不可。所属を\`P\`へリンクしただけで\`K\`境界の形状も位置の妥当性も得られない。

## 3. 時代と権利の安全ゲート
公式資料:
1. https://codh.rois.ac.jp/province/ : ID一覧と分割前後の別レコード（2025-09-19公開）。
2. https://geoshape.ex.nii.ac.jp/kg/ : **幕末の国・郡境界**を提供。旧国85件・旧郡806件、**CC BY-NC**、指定クレジットと商用利用の問い合わせ要。
3. https://codh.rois.ac.jp/policy/ : CODHは資料ごとに利用条件が異なるので使用前に個別ライセンス確認と明記。
4. https://geoshape.ex.nii.ac.jp/kg/resource/K31.html : \`K31\`（Geoshape陸奥）は\`P115\`にリンク。**幕末地図の形状が1689年\`P002\`の証拠になるわけではない**。

CODH ID一覧の単純な参照リンクを追加するが、データ利用許諾全般・再配布・画像・面形状の権利がクリアされたとは記録しない。\`review_status=pending_human\`、\`public_use=draft_only\`、\`rights=unverified\`を維持する。CODHサイトのフッターのクリエイティブ・コモンズ表記だけから、**個々のデータセットやGeoshape境界を同じ条件で利用可とは推定しない**。

## 4. 今回の採用・不採用・保留
**採用**
- 同じ独立Coreを再利用。旧国IDだけを小さな相互参照モジュールとして追加（\`src/historical-gis/codh-province-ids.mjs\`）。
- \`adaptBashoPrototype\` へ省略可能な\`codh_province_id\`、\`codh_id_match_status\`、\`codh_id_source_url\`を追記（GeoJSON Schemaにも任意フィールド追加）。
- 1689の武蔵/陸奥と、1868陸奥、1185の不適用、P002≠P115、公開ゲートをテスト追加。

**不採用**
- 別\`kyukoku-engine\` repo/パッケージを正本として運用しない。既存Core/テスト/UIを新試作で置換しない。
- 旧国名・現代座標の一致のみから行政的所属を確定しない。
- GeoshapeのCC BY-NC境界データを無断バンドルしない。幕末ポリゴンを1689/1185図形として用いない。
- 境界変更の暦年月日不明のまま1868をP115/P113等へ機械一意判定しない。

**要追加検証**
- ZIP取得後、15件のテスト名/入力/期待結果を49+今回の追加テストと比較して、実際に新たな観点のものだけ移植。成功報告は再実行の代わりにならない。
- ZIPのAPI/IDフィールド/ライセンス注記を直接diffして、今回作った相互参照への置換可能性・不足・競合を評価。
- \`P\`と\`K\`の別名前空間を型またはschemaで強制するか、他年代をどう段階的に承認するかの契約策定。
- 現行Bashoの\`old_province\`の資料的妥当性の個別監査。ID表の正しさだけでは当該地点の所属は確定しない。
- CODH国・地域IDデータセットのバルク再配布権利は個別確認（現段階は手動で照合した2 IDのみ）。
