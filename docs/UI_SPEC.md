# UI_SPEC.md — 最初のインタラクティブ地図（v0.1）

更新：2026-10-17 ／ **プロトタイプコードをリポジトリに登録済み、ブラウザ実機未検証**

## 1. 目的

地点の文学的説明を読む動作と、現在の地理を探す動作を一つの画面に組み合わせる。
一地点は「古歌／芭蕉／現代」と「旧国名（1689年を基準）」をもつ。

## 2. 画面構成

- **ヘッダー**: Basho Atlas、構想書へのリンク。
- **注意書き**: 地図ピンは現代の参照地点。古い道路・芭蕉の正確な足跡ではない。
- **地図ペイン**: Leaflet 1.9.4、OSMタイル、3地点のピン、地点一覧、旧国名フィルタ。
- **比較カード**: 地点名、旧国名バッジ（武蔵国／陸奥国）、文学解説3層、探究の問い。
- **出典**: 地点・旧国の根拠資料への直接リンク。
- **現在地の周辺検索**: 明示的ボタン操作でOpenPOIに最大12件問い合わせる。取得した施設は小さなピンで表示。
- **フッター**: 旧国名の説明・GitHubへの導線。

## 3. 操作と挙動

| 操作 | 期待される動作 |
| --- | --- |
| 「すべて」／「武蔵国」／「陸奥国」を選択 | 地点リスト・ピン・表示数・地図範囲が更新 |
| 地図のピンを選択 | 比較カードの地点を変更。地図はそのまま |
| 地点一覧を選択 | 地点切替、地図をその地点へ移動 |
| 三層のタブを選択 | 文章を切替。左右矢印キーにも対応 |
| 「周辺を調べる」を押す | 半径300mを一回検索。地点切替時は前の検索を中断 |
| API検索でエラー | 施設欄に取得不可を表示。文学カードは維持 |
| 地図CDNの不調 | 読める範囲では地点一覧・文学カードを継続 |
| 画面幅が990px以下 | 地図ペインと比較ペインを縦並び |

## 4. 精度と安全性

- GeoJSON互換の座標順は[経度,緯度]、Leafletの表示座標順は[緯度,経度]。
- ピンは現代資料館・史跡指定地・五大堂。芭蕉本人の正確な位置を意味しない。
- 確定教材データとは別ファイル `data/prototype-locations.json` を使用し、`draft_not_for_verified_teaching` を保持する。
- OpenPOIの `licenses` / `attributions` の文字列は、テキスト要素として表示する。HTMLとして解釈させない。
- APIの結果が半径外に出ないよう距離計算で再検査し、座標が空の項目を除外する。
- POIについて営業中や存在確実と断定しない。自動連続クエリや一括ダウンロードをしない。
- OpenStreetMapの著作権表示・通常のキャッシュ挙動を維持し、タイルの大量先読みをしない。

## 5. 未完成・境界

- **旧国境ポリゴン**: 未実装。幕末境界と1689年を区別できる説明、CC BY-NC等の検証後。
- **芭蕉の経路線**: 未実装。出典付きの推定区間が確立するまで線を引かない。
- **古典本文・古歌の逐語比較**: 初期は校訂未了なので説明ドラフトのみ。
- **高度な現代POI分類・施設詳細**: 将来課題。API応答型の実機検証後に調整。
- **地図タイルの本番利用規模**: 将来必要なら別事業者・利用規約を審査。
- **実機QA**: iPhone Safari、Android Chrome、デスクトップの確認は未実施。
- **GitHub Pages**: 現時点では公開操作をしていない。ソースコードは公開リポジトリ上。
