## 2. 最小受入機能

| 対象 | 実装内容 | 注意点 |
| --- | --- | --- |
| 三層比較 | 「古歌」「芭蕉」「現在」の3枚を並べる。狭い画面では縦並び | 実機幅での読みにくさ確認待ち |
| 表示切替 | 三層比較／古歌／芭蕉／現在の4ボタンで一層表示 | `aria-pressed` の状態更新を実装 |
| 古歌 | 能因『後拾遺和歌集』518、源頼政『千載和歌集』365 | DLMの翻刻表記を元にした**未監査データ** |
| 芭蕉 | 『おくのほそ道』白河の関段の秋風・紅葉・青葉の表現 | 校訂本文。原典異本との人手照合は別途必要 |
| 曾良 | 「卯の花をかざしに関の晴着かな」は**書物上の曾良の句**として示す | 芭蕉作と誤表示しない |
| 語句の対照 | 「秋風」「紅葉」「青葉」を押すと本文内の同一語をハイライトし、解釈文を切り替える | 「どの和歌に直接依拠したか」は校注に基づく解釈 |
| 現代史跡 | 白河市の国指定史跡、松平定信1800年比定、1966年指定 | **現在の遺跡・記念地点を1689年の歩行点として扱わない** |
| 地図 | DLMの文学名所代表点をLeaflet/OSMで表示 | 国指定史跡の面の境界を示さない。地図失敗時は文学カード表示を維持 |
| 典拠 | DLM、校訂本文、市の文化財説明、文化遺産オンラインへのリンク | 本文・画像・現代語訳の再配布と閲覧を区別 |

## 4. 文学上・地理上の注意

**古歌**：DLM XLSXで能因`後拾遺(518)`、頼政`千載(365)`を確認。原写本・底本画像に照らした逐語監査は未完了。よって`human_review=pending_human`、`public_use=draft_only`。

**芭蕉本文**：「秋風」「紅葉」と「青葉」の関係を、校注に基づく読解候補として表示。少なくとも**芭蕉の実景**と**古歌のイメージ**を同じ内容として正規化しない。

**現在の地理**：DLM文学名所の代表点[140.228417, 37.047115]（**経度, 緯度**）を参照ピンにする。白河市は指定地を「旗宿関ノ森ほか」と記録。松平定信1800年の考証と1966年指定は、1689年の芭蕉の歩行点を確定したことと区別。

**旧国名**：「陸奥国」は1689年の参照ラベルのみ。専用`kyukoku-engine`の年代別APIが定着するまでは境界線・自動判定を行わない。

**写真**：権利確認の手間を避け、今回の試作には外部写真を転載・再配布していない。
