# 旧国名と歴史地図レイヤーの設計（v0.1）

更新：2026-10-17 ｜ 状態：**旧国名ラベルは試作実装、国境ポリゴンは未実装**

## 1. 何を表示するか

- 地点に「**旧国名（1689年ごろの区分）**」を付ける。
- 同時に現在の自治体名を表示する。
- 旧国名は当時の行政地理を理解する**参考ラベル**であり、「芭蕉がここを歩いた」「古い樹木の正確な位置がここ」という保証ではない。
- 都道府県境の線を旧国境と見なさない。
- 明治期の国名を江戸中期へそのまま投影しない。

現時点の試作地点：

| 古典上の対象と現在の参照地点 | 現代の行政区域 | 芭蕉の時代の旧国 | 点の意味 |
| --- | --- | --- | --- |
| 深川（江東区芭蕉記念館） | 東京都江東区 | **武蔵国** | 現代の記念館の位置。1689年出発地点そのものではない |
| 武隈の松（二木の松） | 宮城県岩沼市 | **陸奥国** | 現代の名勝付近の参照座標 |
| 松島（五大堂） | 宮城県松島町 | **陸奥国** | 松島という広い景勝地を代表する現代の五大堂 |

## 2. 年代基準と区分の罠

- 芭蕉の『おくのほそ道』の旅は1689年。その基準で東北の両地点は**陸奥国**。
- 陸奥国は明治元年（1868年）12月7日に複数国へ分割された。近代の「陸前国」を1689年の地名表示にそのまま当てると**年代錯誤**を起こす。<https://crd.ndl.go.jp/reference/entry/index.php?id=1000038375&page=ref_view>
- 松島町は町史で当地を陸奥国と記述している。<https://www.town.miyagi-matsushima.lg.jp/page/1319.html>
- 岩沼周辺の古代・近世の地名関係は岩沼市の調査報告・地名資料に依拠。<https://sitereports.nabunken.go.jp/files/attach/44/44738/115394_1_%E5%8E%9F%E9%81%BA%E8%B7%A1%E7%AC%AC%EF%BC%91%E6%AC%A1%E8%AA%BF%E6%9F%BB%E3%81%BB%E3%81%8B.pdf>
- 江戸深川は武蔵国に含まれる。武蔵・下総の境界自体は江戸初期にも変遷したため、**国境ポリゴンは年代・典拠ごとの監査が必要**。<https://www.city.katsushika.lg.jp/history/child/2-6-1-42.html>

## 3. 旧国境データ候補の確認と制約

**国立情報学研究所・CODH「旧国・旧郡境界データセット」**:
<https://geoshape.ex.nii.ac.jp/kg/>

- 江戸時代**末期**の国境・郡境に基づく。
- 2026-10-17確認時点で旧国85件・旧郡806件と公表。
- ライセンスは**CC BY-NC**。クレジット要求：
  『旧国・旧郡境界データセット』（CODH作成）「幕末明治地勢地図境界データ」（人間文化研究機構作成）を加工 doi:10.20676/00000454
- **1689年の境界の一次資料ではない**。時差約180年の違いを必ず画面上で説明する。
- 非営利利用条件・出所クレジット・素材の再配布を確認するまで、データ本体のコピーやタイル埋め込みは行わない。
- 他のデータセットが見つかっても、配布条件と年代を評価したうえで採用する。

現段階では **旧国名バッジの表示のみ**を採用。国境線・塗り分け・旧郡境界は延期する。

## 4. スキーマ拡張

現代参照地点 `data/prototype-locations.json` に以下を追加済み。

```json
{
  "old_province": {
    "name": "陸奥国",
    "reading": "むつのくに",
    "basis_year": 1689,
    "source_url": "https://..."
  },
  "coordinates": [140.862483, 38.106731],
  "coordinate_accuracy": "published_site_reference_approximate",
  "historical_route_confirmed": false
}
```

本番のデータモデルに接続する際は旧国を独立ID（`province_id`）化し、`valid_from`/`valid_to`、別名、ソース、確度を持たせる。1地点が時代に応じて異なる旧国へ所属するケースにも対応する。

将来の地図UIで旧国境をONにする場合、表示は必ず「**幕末期の国境参考図**」など**原データの年代を表す名称**にする。1689年の地図再現と呼ばない。

## 5. 現代地図タイルの利用

試作にはLeaflet 1.9.4とOpenStreetMapの公式タイルを採用。
- <https://leafletjs.com/download>
- <https://operations.osmfoundation.org/policies/tiles/>

表示中の範囲だけ読み込み、無制限のタイル事前取得・オフライン配布を実装しない。著作権表示は地図右下に維持。公開規模が拡大した場合は利用規約を満たす別タイル提供元への切替を検討。

国土地理院の標準地図・淡色地図は第二候補。国土地理院によるとこれらの多くは基本測量成果で、場合によって申請が必要である。出典表記のみで常に自由利用可能と誤解しない。
<https://maps.gsi.go.jp/help/use.html>
