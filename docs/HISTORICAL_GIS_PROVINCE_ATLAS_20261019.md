# 旧国名アトラス：単体品質強化 v0.2 Research Preview
更新: 2026-10-19
位置づけ: CODHの国・地域名称**索引**、時点別適用の慎重な判定、現代参照点地図を統合する独立調査UI。
URL（開発サーバー）: `/kyukoku/`。**このブランチはDraft PR、一般公開済みとは主張しない**。

## 1. 独立ページの目的
既存 `basho-atlas` 本体や `genpei-sandbox` と別の単体ビューにし、旧国名エンジン自体の精度・運用上の分かりやすさを検査できるようにした。全国索引に国境ポリゴンが存在しないことは未完成なUIエラーではなく、根拠のない境界線を描かないための仕様である。

```text
kyukoku/index.html + kyukoku/styles.css + kyukoku/app.mjs
    ├── src/historical-gis/province-index.mjs ← 検索・ID関連・年代ステータス（Core）
    ├── src/historical-gis/codh-province-ids.mjs ← 確認済み1689名称ID 2例
    ├── data/historical-gis/codh-province-index.json ← CODH公式88件のID索引
    ├── data/prototype-locations.json ← 芭蕉の現代参照3点（読み取りのみ）
    └── data/historical-gis/yashima-basho.sample.geojson ← 屋島の現代広域代表点（読み取りのみ）
```

## 3. 全国索引と正確性の境界
- `data/historical-gis/codh-province-index.json` は **CODH国・地域IDの全88件**の名前・IDと明治期の関連関係を参照する。70件すべてを「同質な68令制国」と表示しない。P001は蝦夷地、P070は琉球で歴史的な扱いが異なる。
- 同じ`陸奥`でも分割前`P002`と分割後`P115`は別レコード。分割後の`P100–P117`を1689年などの古い年代にそのまま適用しない。
- 地名検索（完全一致でない部分一致）と、歴史上の国名の適用可否（`explainProvinceYear`）を分離。全件検索可能でも、**1689年の`武蔵=P010`と`陸奥=P002`以外の年代付き所属は未監査**。
- 1868年`陸奥`は変化の年月日を個別確認するまで`transition_undetermined`。検索で`P115`が出ても自動的に選ばない。
- 日本語の読みの検索補助はごく少数の手動検証例（武蔵、陸奥、阿波、讃岐、膽振→胆振表記）だけで、全国88件の読み・異体字を網羅したと誤認させない。
- 現代地図上の4点は**現代施設と現代史跡の参照位置**。1689年に関連するBasho旧国ラベル候補は監査前であり、確定所属を表す色分けではない。1185の屋島合戦の正確な位置、旧国境線、港、戦路を描かない。
- 独立UIのソース・国名データの権利表示に、`source_specific_terms_pending_human` を維持。歴史境界データ・画像・地形の再配布は別途許諾と版管理が必要。

## 4. UIの機能と利用上の注意
- 左：キーワード（国名、`～国`、CODH P ID、手動確認済み少数読み）と区分（70/18）で検索。重複する`陸奥`は2候補を両方表示。
- 右上：Leafletの**現代地図**。現代参照点4個のON/OFF。国境は描画しない。選択地点に紐付いた参照点へは明示ボタンで移動し、全体へ戻すことも可能。
- 右下：年の入力・1185/1689/1868プリセット。ステータス（IDの対応のみ、未監査、境界年保留、時代対象外）と関連IDの切替、出典へのリンク。年が変更されても仮の国境線を生成しない。
- モバイル：地図を上段、名前検索を下段。狭い画面でもスクロールでき、チェックボックス・番号入力・リンクはキーボード操作に対応。動きを抑えるOS設定も尊重。
- Leafletや地図タイルのネットワークが落ちても国名検索・年代・出典のテキスト機能は利用可。ただしJSON自体の読込みが失敗すると検索は不可能で、HTTPサーバー経由での起動を案内。

## 5. 検証方針と完成までの未解決課題
1. `tests/historical-gis-province-atlas.test.mjs` が全88 ID・明治関連・重名・時代不確定・非描画・ソースURI・a11yマークアップを機械検証。その他のShared GIS/Coreの既存全テストも同じPR CIで継続検査する。
2. これらは**コード品質検証**であり、地名史料の全件監査、全国レイヤーの地理精度やブラウザ実機操作を保証しない。ブラウザ実機QAは別ゲート。
3. 時代ごとの国名・境界変遷を包括的に扱うには、個別史料に紐づいた`claim_id`・有効年代の根拠・異説・日付粒度・レビュー状態を全件で整備する必要がある。CODHの88IDだけから機械推定しない。
4. 実際の全国旧国境表示には、目的年に適合した資料と**ライセンス許可**が必要。Geoshape幕末データについては外部閲覧リンクを維持。独自配信の可否と利用形態（営利/非営利）を人手で判断するまではバイナリやGeoJSONを同梱しない。
5. 別セッションの独立`kyukoku-engine v0.1.0-dev`ZIP/15テストの実バイトは引き続き未入手。比較・非重複テスト移植の最終判断は取得後。

## 6. 受入対象外
自動ジオコーダを国判定に使用、幕末境界の1185年への投影、OpenPOIのジャンル由来の国名推定、史料不在の代表点追加、ゲーム移動速度のGIS経路への書戻しは**行わない**。
