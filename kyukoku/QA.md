# 旧国名アトラス：実機スモークテスト（v0.3）
更新: 2026-10-19 / W1 実機確認用チェックリスト。**実施記録ではない**。

## 起動
このリポジトリのルート（`kyukoku/`の一つ上）でHTTPサーバーを起動：
```sh
python -m http.server 8000
```
同じPCで `http://localhost:8000/kyukoku/` にアクセス。WindowsのPython起動名が`py`の場合は`py -m http.server 8000`。ファイルを直接ダブルクリックする`file://`起動では、`fetch`によるJSON取得が失敗する可能性がある。

iPhoneでの確認は、PCと同じLAN上からPCの**LAN内IP**と適切に許可したポートを用いる。外部公開や認証不要のポート開放を求めない。画面幅390px等のブラウザ模擬検査は実機確認の代わりにならない。

## 優先度P0：最短の正常系・異常系
| No | 操作 | 期待値 |
|---|---|---|
| 1 | 「武蔵」検索、1689を選ぶ | P010。ID対応のみと表示。国境や地点所属が確定したとは書かない |
| 2 | 「陸奥」検索 | P002とP115の両方が表示され、明治分割前後を区別できる |
| 3 | P002を選び1868へ変更 | 境界年の確定不能を表示。P115へ勝手に遷移しない |
| 4 | 1185にして讃岐を選択 | 史料未監査の表示。中世の讃岐国境ポリゴンを生成しない |
| 5 | 年を空にする・10000と入力する | エラー表示。以前の年の判定は残らず、関連点の強調も停止 |
| 6 | 年を1689へ戻す | 正常判定に復帰し、エラー表示は消える |
| 7 | 参照点の表示OFF/ON | 点のみが消える／戻る。年代や国IDの判定は維持する |
| 8 | 「関連する現代参照点を見る」／「全国へ戻る」 | 点への移動、全国位置への復帰。史実の位置との混同なし |
| 9 | 検索結果のボタンをTabとEnterで選ぶ | フォーカスが検索領域内に保たれ、選択状態を識別できる |
| 10 | 地図タイルの取得を開発ツールでブロックして再読込 | 背景地図取得失敗を表示、国名検索・年代・参照点は利用可。「背景地図を再読込」が動く |
| 11 | Leaflet JSを遮断して再読込 | 地図フォールバックを表示。国名検索・出典は利用可能 |
| 12 | JSON索引ファイルを遮断して再読込 | 検索できない理由を明示。空の結果を実在データ0件と偽らない |

## 必須の環境別チェック
- **PC Chrome/Edge**：No 1～12、キーボードとズーム。
- **iPhone Safari**：No 1～9、画面狭幅で検索欄が地図より先に来ること、入力中のスクロール・タッチ領域。
- **補助確認**：幅320/375/390/768/1280 px、OSの「視差効果を減らす」、画面拡大、ダークモードが設計意図と衝突しないこと。
